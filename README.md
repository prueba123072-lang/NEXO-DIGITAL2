# NEXO DIGITAL

Periódico digital móvil hecho con HTML, CSS y JavaScript (un solo archivo `index.html`).

- Noticias por categorías, búsqueda y favoritos
- Redacción de noticias con almacenamiento local (`localStorage`)
- Suscripción y avisos por correo con EmailJS
- Documentación: evidencias, correcciones, código fuente y manuales

`Screen-Recording.mp4` es el video de demostración de la app.
